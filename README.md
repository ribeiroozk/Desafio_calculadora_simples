# 🧮 Calculadora Simples — React JS

## 📖 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma **Calculadora Simples utilizando React JS**.

A aplicação permite que o usuário informe dois números, escolha uma operação matemática e visualize o resultado diretamente na tela.

O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais do React e a criação de componentes.

## 🎯 Objetivo

Desenvolver uma calculadora funcional utilizando React JS, aplicando conceitos de:

- Componentes
- Estados
- Eventos
- Formulários
- Operações matemáticas
- Renderização de informações
- Estilização com CSS

## ⚙️ Funcionalidades

A calculadora possui as seguintes funcionalidades:

- 🔢 Inserir o primeiro número
- 🔢 Inserir o segundo número
- ➕ Realizar adição
- ➖ Realizar subtração
- ✖️ Realizar multiplicação
- ➗ Realizar divisão
- 🧮 Exibir o resultado do cálculo
- 🧹 Limpar os campos e o resultado

## 📋 Operações Disponíveis

O usuário pode escolher uma das seguintes operações através de um campo `<select>`:

| Operação | Símbolo |
|----------|---------|
| Adição | `+` |
| Subtração | `-` |
| Multiplicação | `*` |
| Divisão | `/` |
